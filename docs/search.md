# 全站检索与统一年份入口

`search/` 是五卷共用的静态检索入口，首页有可直接提交的搜索表单，各分卷页头也可进入。无服务端、账号或地图依赖；原分卷 schema 和链接继续保留。

## 使用与纪年

- 输入人物中文名、拉丁／希腊文原名或别名，事件标题／正文、剧本标题／开局以及章节标题／正文。人物只索引最多240字的首段简介或任职摘要，不是完整传记全文检索。多个词按“全部词都命中”检索；姓名／标题完整命中优先于摘要提名。
- 忽略大小写、空格、标点和 Unicode 重音；希腊文终末 sigma 与普通 sigma 等价，拉丁姓名 J/I、V/U 视作检索变体。这只扩展检索，不参与身份合并。简体中文、源资料已有译名和人工增补的常见异译均可检索，不宣称覆盖所有译法或自动音译。
- `前44年`、`公元前44年`、`44 BC/BCE`、`BC44`、`-44` 明确表示公元前。`公元44年`、`AD44`、`44 CE`、`+44` 明确表示公元后。全角数字可用。`44` 或 `44年` 并列解释为公元44年和公元前44年，不静默选择纪元；超出范围的一种解释也保留说明。
- 内部使用负数公元前、正数公元后，没有0年。前1年的下一年是公元1年。年度导航从 `project.json` 生成，前509、前27、395、476年分别列出相邻两卷。只有输出共和国 URL 时转换为正数 BC 键。
- 年份检索还显示本年已收录任职／称号阶段、事件及剧本章节。人物显示的是本卷收录范围，非生卒年；复位的间断不会被当作连续在位。王政未定年事迹可按文字查找，不会加入任意年度。

结果分人物、事件、剧本、章节，附卷别、日期、纪年说明、命中摘要及高亮。分卷与类型可组合筛选；大结果集逐批展开，结果总数始终显示。空结果、无效筛选、超范围年份和索引失败均有明确说明，失败可原页重试。查询与筛选存于 URL 查询参数，例如 `search/?q=芝诺&period=byzantine&kind=person`，刷新、分享及浏览器前进后退均恢复条件。年度类型只显示年度入口。

“隐藏内容摘要”在当前浏览器保存，尊重既有共和国防剧透偏好。搜索仍显示命中的标题与名称；进入共和国后继续遵守原来的正文揭示开关。

## 索引与导航适配

`scripts/build_search.py` 从五卷 `data/<period>/records.json`、共和国 `stories.json`、`project.json` 及 `data-source/search/aliases.json` 离线投影到 `data/search/index.json`。`build_site.py` 在发布前重建，随后使用原有资源清单生成指纹。地图、底图、来源全文和完整传记不进入索引，搜索页只请求这一份 JSON。初版为1,190条本卷人物、2,082条事件（包括36条未定年王政事迹）、10个剧本和59个章节，共3,341条。交界身份仍分卷保留，不能把这些数量解释成独立历史人物或去重事件数。

索引原始约1.43 MB，Python gzip 压缩约333 KB；这只是本地字节数，非线上传输或延迟测量。日期入口由轻量的时期端点生成，不为2,206个年度复制索引对象。浏览器归一化一次后在内存检索，请求共享、20秒超时、失败清除请求状态；较晚完成的请求只渲染当前 URL 条件。

索引条目 key 为 `(period, type, localId)`，不建立跨卷身份。人工别名表只指向明确的本卷人物ID；失效目标导致构建错误。本次别名是现有姓名、原名及正文的查找变体，不新增传记断言、来源核读或跨卷身份依据。

四卷已有完整人物路由。共和国人物结果进入一条实际任职年度，用 `focus=person:<id>` 定位并展开人物卡；不冒充尚未实现的完整生涯页。事件通过 `focus=event:<locator>` 定位年度条目，未定年王政事迹进入相关人物档案。章节通过 `focus=chapter` 定位阅读区。`shared/search-target.js` 在各卷路由完成后处理这些可选提示，未知提示不影响年度正文。

王政 locator 使用既有事件ID；其他卷目前以年度事件数组序号定位。这是发布版本内的阅读定位提示，不是新建的稳定事件标识；修订或重排资料后链接仍到达原年度，但条目序号可能变化。PR06 的事件ID建模应再替换这些提示，不能将本索引当成完成了该数据迁移。

## 编辑与验证

修改分卷文字／人物／剧本资料并重建后，运行：

```sh
python scripts/build_search.py
npm run test:search
npm run build
npm run validate:release
npm run test:search-ui
```

提交 `data/search/index.json`。发布构建会再次离线重建；CI 在全部分卷文字重建后比较索引，`validate` 包含索引及纯搜索回归，`test:ui` 包含搜索浏览器回归。

`test_search_index.py` 检查已提交索引与来源一致、全人物／事件／章节覆盖、有效任职和事件目标、失效别名拒绝及无地图的体积上限；`test-search-engine.cjs` 检查纪元语法、四个交界、全部人物可检索、异译／重音／筛选、同名不合并。`test-search.cjs` 使用真实 HTTP、指纹资源及根路径／Pages子路径，覆盖各类结果定位、刷新与历史、分页、键盘、四种宽度与明暗主题、摘要隐藏、仅请求索引、过期加载保护，以及 HTTP／网络／JSON／schema／20秒超时恢复。

检索是既有资料的阅读入口，不是证据判定：正文提及人物不表示确认其参与某事件，结果为空也不表示历史上不存在此人或此事。原资料的传统纪年、背景过程和异说继续显示。
