# 人物并排比较

`compare/`覆盖五卷全部1,190份本卷人物档案，按现有七组人工跨卷身份投影为1,183个选择条目；权力专题复用西塞罗、阿格里帕与伊琳娜，并补充17位独立人物，合计1,200个可选人物条目。保留全部1,566项原官职／称号阶段与115条已有明确人物关联的事件。权力专题的20份档案、23项角色另列，观察范围不成为连续任期，没有帝号者不成为皇帝。

## 阅读与入口

首页、五卷与各专题导航均提供“人物比较”。本卷人物页、共和国人物页、跨卷总档案、权力档案、全站检索人物结果与时间轴阶段详情可将当前人物带入A侧，再检索另一位。支持中文、拉丁文、希腊文无重音输入、别名和分卷筛选；结果分批展开，保留任年范围作同名区分。相同姓名和本卷ID不自动合并。共和国193个身份待考条目与尚待审查的同名候选仍按原记录保留，1,200是选择条目数，不是已考证的独立历史人物总数。

十组专题涵盖奥古斯都与提比略、1042年两姐妹、芝诺与巴西利斯库斯、两位查士丁尼、四帝共治、紫室与主政、晚期父子争权、两位摄政者、王政传统与同名不同人。专题只是已有资料的阅读入口。

例如：

- `compare/#preset=zeno-basiliscus`
- `compare/#a=empire%3Aaugustus&b=empire%3Atiberius&year=-1`
- `compare/#a=global%3Aroman-zeno&b=byzantine%3Abasiliscus&mode=main&year=475`
- `compare/#a=power%3Apulcheria`（等待选择另一位）

可以对读身份、宫廷、王朝分类及依据、原传记、任职摘要、称号、明确编订的再次掌权、角色与行动入口、关联事件和逐项来源。生卒日期目前没有统一结构化字段，比较页保留未知，不从任期推算寿命、不从正文自动抽取。原传记中的出生、死亡叙述仍可展开阅读。紫室资料保留原卷标签及说明，不凭父亲在位推断。

同一时间坐标按原卷与身份分行；浅色外框为日期窗口，深色为两端窗口之间，传统／异说用虚线。条形和完整文字列表可互相定位；同一人的多段经历不连接间隙。未定年的塔提乌斯仍保留完整列表，不被放到每个传统王年。手机提供同样文字，不依赖图形完成阅读。

## 可比范围与时长

默认包含全部原官职及称号。可改选帝号（含共帝、争位、区域、流亡，不含恺撒）、主线／宫廷皇帝、共帝或共和国官职。共帝筛选只选原卷独立分段的`junior`记录；古典帝国部分共治合在`central`阶段中，不自动拆出为新增任期，须对读原阶段与实权提示。筛选无结果不表示没有共帝经历。身份筛选影响时长、图形、重叠和同年身份，不删改原人物的概览、复位说明、角色与关联事件。明确编订的主政提示来自原时间轴，不将`central`自动解读为独掌实权。

时长逐卷显示，永不将跨卷重复阶段相加。同一卷同一人的重叠阶段取区间并集，避免恺撒与奥古斯都等交叠重复计算。确日沿用帝国原卷的儒略历口径；仅知月／年的边界使用推算儒略历作数学界限，不重建早期共和国民用历。使用历史年，前1年后直接接公元1年；天数不依赖JavaScript `Date`或现代公历。所有数值是日标签差，不判断日内时刻，不能当作确切在位时数。

- 两端确日：终点日减起点日，表示端点经过时间，不再加一。不推断交接日的时刻；同日端点显示“日内时长未知”。
- 仅知月／年：该月／年首末日仅作可能端点的数学边界。最短区间用最晚起点至最早终点，最长区间用最早起点至最晚终点；最短可为0。逐段取并集后显示范围，不把1月1日冒充即位日。
- 传统、约年、异说、未定年不换算天数，另列排除项数；部分条目可算时清楚标出可比覆盖，不能当作完整任期总长。
- 权力角色的观察年代、行动发生年不纳入帝号／官职计时。原王期传统年数仍在原叙述中展示，与含端点的年度桶数量不同。

“重叠”逐对保留原阶段。两段确定性端点之间有正日差的共同区间时，显示“端点资料支持存在重叠”及共同经过时间下界。仅可能端点窗口相交、同日交接、传统或异说时，显示“可能重叠，无法确认实际同时在任”。这不判断政治共治或承认关系。跨卷重复表述不累计重叠总时长。

“同年身份”显示该年内可能出现的阶段，包括同年先后和异说候选窗口；不主张全年任职。年度入口只指向原卷实际收录年，共和国显式转回正数BC旧路由。没有本年任期不表示没有活动。

## 复位与关系依据

`data-source/compare/editorial.json`单列8人的10项再次掌权记录：芝诺、查士丁尼二世、伊萨克二世、狄奥多拉、约翰五世、马克西米安、阿塔卢斯和西班牙马克西穆斯。每项指向原阶段，附原传记精确引文；构建验证引文仍存在。芝诺两卷同一复位只编订一次。

分为复位、再次取得统治权、再获拥立／恢复帝号，不把三者混为同一计数。君士坦丁七世、米海尔七世等共帝转主帝不自动算复位，普通多次执政官任职也不算。约翰五世1354年从共帝恢复主帝阶段不计失去帝号后的复位；1379与1390年按原阶段及失位叙述列入。本表是已编订记录，不是宣称穷尽历史；未列入者显示“未编订，不等于从未复位”。计数使用完整原记录口径，不随任期筛选改变。

事件只从现有`byPerson`显式关系汇总，跨卷与跨年按稳定事件ID去重。可看全部、两人共同、仅A、仅B；保留参与者／事件主体／仅被提及的关系及依据。共同关联不证明两人会面或共同参与整条年度摘要，不从任期生成参与者。权力专题行动另给入口，背景关联不升级为直接参与。

本次实际对读的是当前仓库五卷文字、跨卷人工身份、时间轴端点与实权提示、明确事件关系、王朝归组与权力角色。没有新增外部历史事实，也没有在本次重新直接核读古代文献或现代专著。原证据卡与权力资料的核读状态、定位、核对日期沿用原档案，不升级为本次直接查阅；新增复位表仅重述上述既有原文及阶段。

## 构建、恢复与验证

`build_compare.py`只读现有投影与五卷原档案，输出`data/compare/index.json`，约3.12 MB未压缩文字；此为文件字节数，不是线上传输或加载测量。发布构建在时间轴、身份、事件与权力投影之后生成，沿用内容指纹和相对路径。原五卷schema、人物ID、年度、任职、事件、地图与旧链接均保持。

页面只请求比较文字投影，不请求各卷完整records、地图或外部服务。成功值与在途请求共享，20秒超时、HTTP／网络／JSON／结构错误可原页重试；快速换路由使用当前选择。地址保存两人、口径、年份和专题，交换、刷新与前进后退可恢复；无效ID、同一已确认人物、0年和无效条件提供明确恢复入口。

复制失败提供可选择的完整链接；存储受限仍能浏览与切换主题。JSON导出包含版本、选择、完整两人资料、原任期、事件、复位、来源、许可与署名，不只导出屏幕上的筛选结果。代码MIT；内容与投影CC BY-SA 4.0，沿用仓库署名和外部来源说明。

```sh
python scripts/build_compare.py

npm run build

```
