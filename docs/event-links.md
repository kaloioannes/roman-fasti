# 人物—事件—地点：有依据的阅读路径

年度原条旁的「人物／地点」可以直接打开卷内人物或地点档案；「查看逐项关系依据」进入同一稳定事件对象。人物专页列出明确关联的记事，跨卷总档案只汇总人工确认属于本人的卷内关系。地点目录支持中文及异名查找，每份档案列出相关记事、各条地点角色、关系依据、相关年度与地点身份出处。地点可以通过全站搜索的「地点」类型找到；多卷涉及同一地点时分卷结果进入同一档案。

示例：

- `republic/#year=49` → 恺撒人物专页 → 「跨过卢比孔河」 → 卢比孔河地点档案 → 前49年。
- `empire/#year=378` → 事件档案：瓦伦斯与格拉提安分别显示直接参与和仅被提及，原文明确未等格拉提安主力到达。
- `byzantine/#year=1071` → 罗曼努斯 → 曼齐刻尔特 → 地点及年度。巴里独立对象不归为罗曼努斯本人行动。
- `people/#person=roman-augustus` → 共和国与古典帝国的明确事件关系，不用姓名相似自动扩展身份。
- `places/#place=constantinople` → 跨年远征只列一个对象，1202／1203／1204各有年度入口；原摘要、过程与子事件保留各自类型。
- `places/#place=ostia` → 王政建城传统保留未定年，不据王期范围填造发生年。

## 本次编订与证据边界

PR08独立编辑表覆盖85条记事（含传统叙事、年度摘要），编订143项人物及60项地点关系；继承PR06既有关系后，统一投影共129条有关联对象、193项人物关系、68项地点关系、26处地点。数量仅说明提交内容，不是覆盖指标或独立史实计数。没有把全部2,088条对象的正文提名自动转成关系，也没有重写五卷原始记事、人物、任职、剧本或地图。

本次直接核对的是仓库现有记事、显式人物ID、此前已确认跨卷身份、研究说明及沿用引用。**未重新直接核读外部古代文献、译文或现代研究**，新关系引用统一标为`inherited`、核对日期为空；不把前次PR的直接阅读记录冒充本次阅读。引用中的原有定位和具体限制继续保留。新的地点身份只整理原文语境中的城市、河流或区域，不提供新坐标、疆界、控制权或完整地点史。卡庇托尔归于罗马城，拜占庭首都语境归于君士坦丁堡；两个位置精度不同，不能当作同一个精确事件点。米兰协议的地点仅标为提及，不断言后续军事行动都发生在米兰。

关系角色：

| 对象 | 角色 | 含义 |
|---|---|---|
| 人物 | `participant` | 所引片段明确记载其行动；不表示同条年度摘要内全部行动均由其完成 |
| 人物 | `subject` | 遇刺、死亡、被废等事件对象；不改写成主动行为 |
| 人物 | `mentioned` | 提名或叙事关联，不能据此断言直接参与 |
| 地点 | `setting` | 所引行动发生或展开的地点；不包括整条摘要所有行动 |
| 地点 | `subject` | 建城、毁城等记事所述对象地点 |
| 地点 | `mentioned` | 仅被提及，或尚未进一步编订角色 |

原有王政显式人物关系保留PR06的`mentioned`角色及传统性质，不自动升级为可证实的参与。希拉克略在626年仍在外线作战，只标为提及；不把在位皇帝自动列为首都守城者。查士丁尼在位时的541年瘟疫不归为本人行动。资料尚未编订明确关系时，人物页如实提示；这不等于断言历史上没有关系。

## 编辑、校验和生成

`data-source/events/links.json`以稳定事件ID为键，每行包含编辑说明、人物关系和地点关系。人物使用`period/person`二元身份，地点使用独立稳定ID。每条关系必须有角色、说明、原文短引`quote`与非空`references`下标，后者指该事件已有引用的零起始序号。构建检查短引确实出现在原标题或正文中；改写关联片段后必须重新检查关系。这个检查只验证编辑证据仍能定位，不能证明原文历史判断为真。

编辑表显式覆盖所选事件在统一投影中的关系；已有PR06明确关系不能被静默丢弃。未覆盖的原关系仍从`metadata.json`及`events.json`继承，保留原依据与角色，并注明旧编订来源。`places.json`维护地点身份、异名和引用；没有可靠依据的地点不要添加，更不能仅凭坐标检索补出精确地点。

`scripts/event_links.py`由`build_events.py`调用，拒绝孤立事件、失效人物／地点、重复边、无效角色、空依据、失配短引和越界引用。输出的`placeRelations`与兼容字段`places`严格一致；所有`byPerson/byPlace/byYear`反向索引来自同一份事件对象。`byGlobalPerson`仅经PR04确认身份表聚合，按事件ID去重；跨卷原摘要仍是不同对象，不擅自合并相似史实。

生成物：

- `data/events/index.json`含完整关系、引用、编订表定位、角色与反向索引，供事件和地点档案共用。
- `data/events/navigation.json`保留五卷原页所需的名称、角色、依据和链接，不带全部正文与证据卡；目前约96 KB未压缩。原卷文字独立加载，关联失败可单独重试。
- `data/search/index.json`增加地点类型；同一地点在不同卷的搜索结果是分卷入口，不创建多个地点身份。地点的时间范围仅来自已编订记事，不是地点存在期。

正文搜索辅助工具只输出**待审阅候选**：

```sh
python scripts/review_event_link_candidates.py --output ../work/event-link-candidates.json
```

它不会改写关系表，候选不会进入发布数据，同名的多个ID分别保留。命中仅表示文字匹配，不确认身份、行动角色或实际参与。报告不能写进`data/`、`data-source/`、`site/`。对候选的采用必须人工核对语境、人物身份与引用，再显式编辑关系表。

## 路由、恢复和验证

原卷URL及事件稳定ID不变，地点地址为`places/#place=<ID>`；原事件筛选`events/#place=<ID>`继续有效，并链接地点档案。年度采用统一无0年历史纪年，回到共和国时显式转回正数BC。跨年过程、日期窗口和未定年传统沿用事件模型，不推算新年份。

事件／地点档案共享文字加载器：只加载事件索引，20秒中止，复用在途请求与成功缓存，校验数据结构，失败在原页重试，快速换路由不会显示旧结果。原年度／人物及跨卷总档案使用独立可选导航，失败不阻断原文和地图；导航加载时也检查当前路由与节点是否仍在页面中。共和国防剧透会隐藏原条内关系，展开原条后才显示；关联列表另有可操作的展开入口。存储与剪贴板受限时仍可阅读和手动复制。

```sh
python scripts/build_people.py
python scripts/build_events.py
python scripts/build_search.py
npm run test:events
npm run validate
npm run build
npm run validate:release
npm run test:events-ui
npm run test:links-ui
npm run test:ui
npm run test:release
```
