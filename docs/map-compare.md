# 地图阶段对照（PR15）

[打开对照页](https://kaloioannes.github.io/roman-fasti/map-compare/) · [116／117](https://kaloioannes.github.io/roman-fasti/map-compare/#preset=trajan-hadrian) · [1204／1261](https://kaloioannes.github.io/roman-fasti/map-compare/#preset=restoration)

五卷的地图可以选择任意两个已有年度、相邻阶段或专题，在同一投影、比例与视野下并排或滑动揭示。拖动任一地图会同步另一侧，按钮支持缩放、四向平移和重置；手机并排模式上下排列，滑动模式保持同一画幅。分卷首页、地点／事件／时间轴页和五卷年度页均有入口。年度入口以该年为两侧起点，便于自行选择要对照的阶段。

## 范围与制图口径

目录涵盖现有四卷疆域的全部图层与王政原年度关联地点，共268个显示阶段组合、12个专题。专题覆盖拉丁姆、布匿战争、图拉真与哈德良、东西宫廷、查士丁尼、1071之后、第四次十字军、流亡与复国、晚期GIS缺口，以及前509、395、476三种跨卷对读。专题中的事件是明确编辑入口，区间列表另外提供两个年份之间的记事和主题筛选。

每侧始终分别列出：所选年度、整套图层组合的显示阶段、单层的适用期、原始源阶段、制图精度、原图注、来源与许可。这些说明在滑动、缩放与加载失败时仍保留为文字，不收进默认关闭的折叠项。原GIS的0年端点只作为“源0年（原GIS端点）”呈现；不能选择历史0年。共和国新入口采用负数历史年，回原卷时显式转回正数BC路由。

- **王政**：仅沿用原卷王期叙事的关联地点与粗略坐标。交接年合列两王的关联地点，空位期不补点；塔提乌斯未定年共治不被强制展开。点位不表示当年领土、事件现场或控制权。地点等价列表保留全部名称、位置说明及原引用；这些近似坐标不同于PR14重新核读的地点档案。
- **共和国**：前509—338年的五组编辑示意使用虚线，保留逐段史事出处；文本支持史事节点，不提供边线顶点。后续采用原Cliopatria阶段，保留`sourceFrom/sourceTo`，包括前27年显示与源前27—26年范围的区别。
- **古典帝国**：罗马世界外缘合并图层，不划出内战阵营或每位共帝的辖境。116采用源117—126轮廓，117—126采用源127—153轮廓，均明确标为借用近似。395年的共同外缘与双帝国395年东西分层是两种展示口径。
- **双帝国**：保留东／西颜色与原源属性中的年代。476年西部借用源469—475轮廓，仅作退位前参照，不能把年末宫廷终结理解成整个色块在同日消失。帝号、流亡与承认另见年度文字。
- **拜占庭**：保留拜占庭／尼西亚、拉丁帝国、特拉比松的原图层及源阶段。1402借用源1395—1401阶段，1403—1406借用源1407—1414阶段；不以此精确复原安卡拉战役或1403年条约的领土效果。

两个年份落在同一个组合阶段时会明确提示复用原几何。即使分属不同阶段，原多边形也可能相同；相同图形不能证明没有历史变化。跨卷色块增减可能来自收录对象与制图口径。对照页不插值、不变形、不自动创造逐年边界，也不计算面积差、增减百分比或疆域排名。Natural Earth现代海岸仅供方位参考，不是古代海岸复原。

## 变化与事件证据

专题短说明直接沿用既有地图图注、研究说明和原事件的历史范围，逐项连接稳定事件档案。没有增加新的独立史实、疆域几何、人物关系或坐标，也没有将某条事件自动判为某段边线的成因。

区间事件在读者展开后才加载既有统一事件投影，按两侧所选分卷、两端年份之间的明确年代范围筛选，并可按主题进一步筛选。跨年对象按稳定ID只列一次；年度摘要、跨年背景、日期窗口、传统纪年与独立事件继续显示原类型、日期说明和纪年确定性。父摘要与子事件若同时存在仍是不同资料对象，数量不能直接理解为独立史实数量。未定年传统不强行放进区间。每批40条，可继续读完全部匹配对象；事件档案、明确人物、两侧原年度及事件地图可往返。

**本次实际查阅**：核对当前仓库四卷`territories.json`、GIS构建脚本、王政`records.json`、五卷研究说明、统一事件与既有引用。未重新直接核读外部历史文献、Cliopatria原始研究或底图测绘；既有引用的直接／间接查阅状态均保留在原档案，没有升级成“本次已直接核验”。源GIS和历史研究各自局限仍以原卷说明为准。

## 分享、恢复与等价阅读

URL保留两侧分卷／年份、并排或滑动方式、滑动位置、统一视野以及平移缩放。支持专题短链接、刷新、前后退、根目录与GitHub Pages子路径。非法分卷、越界年、0年、非整数和异常视野参数显示可理解的错误及专题恢复入口。复制失败会选中可手工复制的完整链接；浏览器存储不可用时仍可使用全部对照功能。

示例：`map-compare/#ap=empire&ay=116&bp=empire&by=117&mode=swipe`。`ap/ay`与`bp/by`是两侧历史年；`frame`可选`auto/mediterranean/latium/east`，`k/x/y`为视野变换，`swipe`为0—100分界位置。默认116／117专题。

目录、每个所选卷的原疆域、底图与事件分别缓存、共享在途请求、20秒超时并独立重试。只请求选中的卷，成功资源不会因其他资源重试而重新下载。原几何按当前目录核对完整阶段和多边形结构；损坏数据不进入缓存。目录先行显示，地图资源失败后仍能阅读阶段与来源；底图失败时可看原疆域；事件失败不会阻断地图。路由版本防止快速换卷后旧响应写回。原年度文字和地图的加载不依赖新页面成功。

两侧完整的层名、适用期、源阶段、近似、图注和出处提供文字等价内容；王政所有点位也有列表。全部选择、阶段跳转、缩放平移、滑动分界及事件阅读可用键盘操作。亮暗主题沿用全站设置，手机采用单列资料，印刷时滑动图展开为两幅。

JSON导出保存版本、选择与视野、两侧阶段资料、专题入口、原图层及点位出处和逐层许可证；不重新打包大体积几何。中文编辑／投影CC BY-SA 4.0，Cliopatria几何CC BY 4.0，早期编辑示意MIT，Natural Earth公有领域。原几何下载与复建仍在原卷源资料中。

## 维护与验证

`scripts/build_map_compare.py`对五卷作只读适配：逐个原年度读取原卷当前采用的图层集合，相邻年度集合不变时合并为一个显示阶段。阶段ID是`period:from:to`，不取决于文字标题或数组位置；每层保留原几何索引、适用期、源阶段、图注及出处。修改原地图阶段起讫时ID会随范围变化，旧分享URL仍以历史年解析到当前阶段；没有公开依赖内部阶段ID的路由。

专题只编辑`data-source/map-compare/presets.json`，事件键必须存在于统一事件投影。新增／修改原GIS后同时重建目录；对照页按索引与原属性核对，防止目录和几何版本错配。网站构建在事件与地点之后自动重建该目录，并对数据和脚本生成内容指纹。

```sh
python scripts/build_map_compare.py
npm run test:map-compare
npm run build
npm run validate:release
npm run test:map-compare-ui
```

数据测试逐年对照五卷原图层与地点，检查源阶段、借用、确定性、事件引用和可重复构建。引擎测试检查全部原几何、0年与异常输入、深层坏数据、纪元跨越、反向对照和跨年去重。真实HTTP浏览器回归检查12专题、五卷年度入口、相同阶段复用、两侧同步缩放、键盘滑动、分享视野与前后退、导出署名、独立故障／超时／重试、请求竞争、存储及剪贴板受限、320／390／768／1440明暗布局与两种部署路径。全部进入原CI流程。
