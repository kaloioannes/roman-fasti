# 实际权力与摄政

`power/` 是独立的实际权力人物目录与档案。它解释正式身份、具体作用、行动与限制，补充原有统治者纪年，保留五卷的皇帝／官员名录、年度成员与称号任期。没有给人物添加“权力分数”，也没有用婚姻或任期相交推定政治控制。

## 内容与身份

本次编订20位人物、23段角色阶段、53项行动、21项来源记录。数字是编订范围，不是收录配额、历史重要性或可信度指标。角色覆盖Augusta／皇后、摄政、行政授权、宫廷官员、元老与顾问、军事统帅及军事强人。女性按荣衔、资助、危机决策、宗教与行政行动建档，不只作为配偶字段。

西塞罗与阿格里帕复用共和国原身份，伊琳娜复用拜占庭原档案；莉薇娅、小阿格里皮娜、安娜·达拉塞娜及阿格里帕复用PR11的节点。其余为专题补充人物，没有写入原卷皇帝名录。六世纪狄奥多拉与十一世纪紫生狄奥多拉显式消歧；宫廷欧特罗庇乌斯与同名史家不同，西塞罗不与前30年补任的儿子合并。

阶段分为完整所述任期／授权、文献观察窗口及行动年代。年精度不补1月1日；不按角色的最早、最晚记载推断中间始终握有同等权力。伊琳娜780—790年摄政与792—797年恢复共治分列，后来的独治任期仍见原卷；安娜的1081年诏书不据此延伸到未经本次材料核定的结束年。未知行动确年保留空值，没有年度入口。

## 阅读与互链

- 目录可查中文、拉丁文／希腊文无重音姓名、异译、行动与全部编订引用中的作者／译本／定位，组合分卷、角色、记载状态与历史年份范围。裸数字显式解释为公元年，无0年；年代与角色、行动相交，选定角色时须该角色阶段相交，未定年阶段不推入范围。王政没有凭传统传说补凑人物。
- `#person=pulcheria` 是人物稳定地址；`&action=accession` 定位其450年行动；`&section=roles` 定位角色阶段。筛选、刷新、返回、路由后焦点及键盘均保留。
- 每段角色保存作用与限制，每项行动独立附论断、卷章／小节、作者、译本、材料类别、直接／间接阅读范围与核对日期。普尔喀丽娅450年的作用、阿斯帕尔支持利奥等保留争议；研究转述的古代文献不冒充本次直接核读。
- 本人的原档案、王朝节点与本专题双向连接；原统治者页另列“相关权力档案”，明确不是本人的另一份身份。人物间“继续对读”只是阅读导航，不据此追加家族／同盟边。
- 原年度只反查本年显式编订的行动，不能从角色窗口批量生成年度行动。事件页反查手工指定的卡片；卡片明确区分同一事项与相关年度背景。年度摘要不一定记有该行动，不能把其中全部事迹归给该人物，也不能反过来用它代替卡片出处。
- 可复制规范引用、当前行动链接，剪贴板受限时选中文字；下载保留角色、全部行动、连接依据、来源、实际阅读范围、资料版本与许可。全站搜索以独立“实际权力人物”类型索引，不混入皇帝名录。

## 编辑与校验

编辑 `data-source/power/people.json`，源文件是可审阅的研究与论断表，不编辑压缩产物。

- `identity` 必须显式选择 `volume`、`dynasty` 或 `new`。原卷引用携带身份检查；已有辅助节点不能转成重复的新人物。规范全站身份只使用既有人工映射，不按姓名合并。
- `roles` 保存稳定ID、角色枚举、日期、作用、限制及引用。`actions` 保存独立稳定ID、日期、记载状态、说明、出处及可选事件连接；修正文案不更换ID。
- `connections` 是人工选择、附论断依据的原卷人物连接；`related` 只为阅读导航。`event.relation` 是 `context` 或 `same-action`，必须说明链接语义。
- `sources` 保存作者、版本、材料类别、查阅范围、核对日期与局限。间接来源需要明确中间材料；缺失定位、支持论断、无效身份、未定年带数值、0年、失效事件、跨卷／年代不符、重复身份及无解释异说均使构建失败。
- `build_power.py` 生成完整 `data/power/index.json` 和约17KB的小型 `navigation.json`。原页只独立请求导航；缓存成功请求、共享在途请求、20秒超时及可重试，异步完成检查当前插槽和年份，失败不重载正文或地图。
- 重建顺序为人物／事件／时间轴／王朝 → 权力 → 搜索；发布构建自动执行。PR工作流核对生成物一致性，并执行数据和真实HTTP浏览器回归。

```sh
python scripts/build_power.py
python scripts/build_search.py
npm run test:power
npm run validate
npm run build
npm run validate:release
npm run test:power-ui
```

回归覆盖全部档案、身份复用及同名辨识、阶段与出处、年度／人物／事件／节点互链、无重音检索、来源、稳定行动地址、下载与复制回退、键盘、根路径及Pages子路径、320／390／768／1440明暗布局、存储受限、HTTP／网络／JSON／深层结构错误、超时、共享请求及快速换页的过期保护。保留全部既有数据、结构、检索、人物、事件、证据、词典、时间轴、王朝、地图及发布回归。
