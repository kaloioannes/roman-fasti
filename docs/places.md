## 本次范围与实际查阅

保留原26个地点ID，完整编订29份档案：新增奥龙特斯河畔安条克、高卢的尼西亚（尼斯）和比提尼亚阿斯塔科斯旧址。24份档案采用Pleiades的城市／遗址代表点；卢比孔河、阿尔巴·隆加、扎马战场、达尔马提亚和克莱迪昂保留无可采用点位的状态。后两项仍未核实可靠坐标，不能把其他同名聚落借作战场。无点位并不代表没有相关事件。

2026-10-21直接读取Pleiades官方发布仓库的27项JSON，固定版本为[`a7ae25da9f3e872c214725d2a7f2c65f48cfa2c4`](https://github.com/isawnyu/pleiades.datasets/tree/a7ae25da9f3e872c214725d2a7f2c65f48cfa2c4/data/json)。核读字段包括`title`、`description`、`reprPoint`、`features`、`names`、名称标期及署名；没有直接阅读这些条目所引的Barrington Atlas、DARMC原始测绘或全部古代文献。地点专页和导出逐项保留作者、规范URL、固定版本文件、字段定位、日期、许可及实际范围。Pleiades在线单页在本次访问时返回访问验证，未将验证页当作已读地点资料。

对照的官方模型与发布说明：[概念模型](https://pleiades.stoa.org/help/conceptual-overview)、[数据下载](https://pleiades.stoa.org/downloads)。其中地点身份、位置、名称和连接是不同对象；本项目也保留这一差别，没有把外部数据当作能完整覆盖拜占庭各时期的底库。Pleiades代表点可由多处位置综合而来，小数位数不代表事件现场测量精度。采用时舍入到四位小数，统一标为约位，并区分城市级／遗址级。

新增安条克4项事件关系，直接核对仓库现有115、362、526、969年记事的安条克语境，沿用各条原卷引用，没有重新直接核读这些事件的外部文献。每条关系保留短引、原文定位及`inherited`状态；969年的安条克行动不包含同条摘要中发生在宫中的遇刺。没有从提名补建人物参与关系。原五卷人物、任期、年度正文、王期和疆域几何不变。

## 日期、同名、迁址与不确定性

- 尼西亚（比提尼亚／İznik）与尼西亚（高卢／Nice）是两个地点，互相提供消歧链接。全站与目录均可查找；尼斯暂无编订事件，不能借用另一地点的事件。其检索分卷是目录归置，不是存在年代。
- 阿斯塔科斯旧址与尼科米底亚新城分别保留坐标。前264年重建的连接是地理与历史语境，不是把两处位置合并成一个不断移动的点，也不证明所有人口迁移。
- 君士坦丁堡档案说明前身拜占庭与330年后的扩建，现代Istanbul只作现代定位名；不将现代城市边界投回古代。
- Pleiades名称的起讫是文献／资料标期，不是名称开始或停止使用的确年。例如标至640年，不表示此后不再使用；Malazgirt的后世标期也不能拿来证明1071年的战场。名称界面一直显示这个区别。
- `coverage`是本项目前753—1453的检索窗口，不是建城／废弃／主权年代。位置另有`fromYear/toYear`：未知值保留`null`。已知有效范围参与地图选择，范围不符时事件保留在未落点列表。当前代表点的古代有效起讫未单独考证；作为地理参照使用时明确提示。
- 扎马城址和战场不能简单等同；卢比孔河的现代对应及渡河现场有争议；佩卢西乌姆古河口、奥斯蒂亚古海岸与Natural Earth现代海岸不同。阿克提乌姆岸上点也不代表海上战线。

## 阅读与分享

地图支持起止年（负数公元前，无0年）、主题、分卷、事件／人物／地点文字与「仅发生／对象地点落点」组合。范围查询可以显式包含或排除未定年传统；年度图默认排除未定年。跨年过程只显示一个事件对象，年度摘要、独立事件、过程与子事件保留各自类型和纪年说明。界点年可经相邻卷查询，但不产生新事件副本。

同一地点的多条记事共用一个点，点击或键盘Enter／空格显示事件与明确人物，人物关系保留直接参与／事件主体／仅提及。仅提及地点用空心点，筛选可以不让它落点。城市参照点不能证明整条年度摘要都发生在此地。无坐标、无地点关系或被落点筛选排除的条目都保留在等价列表；未落点计数按事件计，点数不等于独立史实数量。

地图有缩放、重置视野和完整等价列表，关闭滚轮缩放以保留页面滚动。列表每批60条，可继续显示所有匹配对象。地点／事件／人物和年度链接双向沿用原稳定URL。筛选地址能刷新、返回、复制；剪贴板不可用时选中文本手动复制。JSON保留版本、地点出处、Pleiades逐项署名与独立许可。年度小型投影只携带事件入口、日期、角色与关系说明，完整事件证据通过稳定事件URL读取。

年度页在读者展开前不请求事件地图数据；新投影约1.27 MB原始JSON，不是网络传输或首屏耗时测量。它保留全部2,088条事件的轻量字段，地图不能让尚未编订地点的记事消失。底图及数据请求各自缓存／复用在途请求，20秒超时，失败原位重试；路由或筛选已改变时旧请求不能写回。原疆域地图的阶段、源年代及近似说明原样保留。事件地图不计算面积或生成逐年疆界。

## 编辑与校验

`data-source/places/gazetteer.json`是地点编辑源；`event_places.py`在事件构建时叠加，保留原地点ID、异名与引用。`data-source/events/places.json`继续提供兼容身份入口；明确事件地点仍编辑`data-source/events/links.json`，未迁移五卷schema。新增地点无事件时需要明确`catalogPeriods`以进入全站目录检索；该字段不证明其历史存在期。

构建拒绝无源位置、越界／非有限经纬度、0年、倒置年代、未知精度、失效引用、丢失旧身份或异名及孤立连接。`build_places.py`从相同事件对象产生`data/places/index.json`；`places/engine.js`按显式关系、日期范围和位置有效期选择对象，不做文字地理编码。发布构建先重建事件与地点，再重建其他专题与搜索，所有新资源走既有内容指纹及相对路径。

```sh
python scripts/build_events.py
python scripts/build_places.py
python scripts/build_search.py
npm run test:places
npm run validate
npm run build
npm run validate:release
npm run test:places-ui
npm run test:links-ui
npm run test:ui
npm run test:release
```

数据测试覆盖全事件保留、确定性、旧引用、同名与迁址、外部对照范围及错误编辑。引擎测试覆盖无0年、跨年去重、未定年、无点列表、地点角色和位置年代；浏览器测试覆盖五卷懒加载、人物往返、筛选分享与下载、无点／未定年、HTTP／网络／JSON／深层损坏／超时／底图失败恢复、请求竞争、键盘、存储受限、明暗主题、320／390／768／1440宽度及根路径／Pages子路径。原有全部回归继续保留。
