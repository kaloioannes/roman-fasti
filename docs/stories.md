每部有开局、关键人物、贯穿问题、章节因果和有边界的结局。章节点并非逐年事件的替代品，正文没有从年度摘要自动拼接。原五卷的人物、任职、原始记事、地图和身份模型保持原样。

## 阅读路径

目录可按分卷、标题、主题、关键人物和编订的中拉希别名查找；查询可用表单写入hash并分享。全站搜索继续使用`story/chapter`类型，保留共和国已有搜索URL；新增六部及42章进入独立阅读页。

- 剧本：`stories/#story=tetrarchy-to-civil-war`
- 章节：`stories/#story=tetrarchy-to-civil-war&chapter=abdication`
- 分卷：`stories/#period=byzantine`
- 原共和国：`republic/#story=written-law&year=451`，旧根目录兼容跳转继续有效。

目录、逐章前后导航、当年档案、关键人物及补充权力档案均可往返。原年度和人物只读约26KB的小型反向导航，不下载全剧或其他卷的完整档案；加载独立超时、缓存、重试，路由变化后不写入旧页面。年度只在编辑明确设置的节点反查，不把两章之间每一年自动关联同一叙述。王政两章可以共用同一年度阅读锚点，稳定章节ID使它们不相互覆盖。

人物链接表示编订的阅读对象；不因“本章谈到”自动写入事件参与关系。原卷ID与`power:`身份显式校验，不按同名或任期重叠推断。新内容已编订可验证的身份；共和国旧版没有可靠ID的开局人物保留文字，不制造匹配。

## 进度与防剧透

`fasti-reading-v1`只在浏览器本机保存每部的`last`与显式`read`章节ID。打开章节只更新上次位置，不自动标为读完；按钮可标记或取消，目录可继续上次阅读、查看已读数。原共和国阅读页也使用相同故事ID与`y<BC年>`章节ID；统一页和旧页互通。重置有明确确认，单部和全部分开。存储被禁止时当前页面保留内存进度并显示无法持久保存，不阻断阅读。

沿用全站偏好`fasti-spoiler-v2`，默认关闭。开启时隐藏开局提示、未读章标题、正文、思考问题、人物与本章引用，页面标题也不泄露未读章题。可逐章揭示，揭示本身不算已读。已读章可以回看；原年度与人物页可能包含后续史实，离开阅读页前有提示。此功能是阅读辅助，不修改、删减源资料。导出剧本含全部正文、出处、版本、方法与许可。

无账号、服务端、分析追踪和同步后端。清除浏览器存储会丢失本机进度；跨设备及导入导出进度属于后续收藏工作，不在本PR引入。

## 实际查阅与史学边界

编辑日期2026-10-21。19项新增来源记录中，18项为本次打开电子正文并阅读指定段落，1项普塞洛斯为沿用原卷引用。来源自身再引的文献不自动升级为直接查阅；共和国适配的29项原版引用全部标为沿用。本次没有校勘手稿、亲验文书或通读未获取的现代专著。

- **李维**：Spillan 1853英译电子版的序言及卷一指定段落，并以原王政研究说明约束纪年。吸纳、空位、努马、财产等级及废王用于解释罗马人的制度记忆。神迹、演说与七王传统不是当代逐年实录；阅读锚点不把未定年事迹升级为确年。
- **拉克坦提乌斯**：Fletcher 1886英译《迫害者之死》7、18—20、24—30、43—48；对话、神助与道德裁判标明作者立场。对读Mathisen的戴克里先和Pohlsander的君士坦丁署名研究相关段落，未依其总索引重定原任期。
- **普罗柯比**：Dewing 1914英译《战争史》I.22—24、II.5—11、22—23；财政、尼卡、安条克和瘟疫相关段落。对读Evans的查士丁尼研究。狄奥多拉演说不是录音，瘟疫叙述不换算死亡率，不以单一灾难解释全部财政变化。
- **双宫廷**：直接读Socrates VII的相关章节、Marcellinus的476年条，以及Mathisen、Nathan、Elton的霍诺里乌斯、狄奥多西二世、瓦伦提尼安三世、利奥一世研究指定段落。476年同时对读原卷流亡任期与已有证据卡；尼波斯到480年的帝号并未被删去。
- **科穆宁**：Dawes 1928英译《阿莱克修斯传》III、VIII、XI、XIII的指定章节；实际阅读的家族安排、行政委托、莱武尼翁、尼西亚、安条克与德沃尔。安娜为父亲及家族辩护；授权和条约是传录，承诺不等同实际控制。1071章保守沿用原卷骨架及普塞洛斯路径，没有本次重核普塞洛斯英译，也未新增战场对白或兵力。
- **1204—1261**：Marzials 1908英译维尔阿杜安的第二次夺城、洗劫、推举与阿德里安堡段落；吉本卷六LXI—LXII公版注本的相关段落。后半仍以旧通史对照原卷为路径，未直接取得阿克罗波利特、帕奇梅雷斯和格里高拉斯原著；这些引文如实视为间接。吉本的民族、性别、人物道德化与必然衰败论不用作结论。这是可继续深化的具体研究限制，不以一组链接宣称原始史料已全面核读。

逐章`references`分别存来源、卷章／小节和支持的论断；来源保存作者、版本、实际范围、查阅方式、日期及局限。解释性问题与跨章综合判断明确作为导读，不把它们反向写成新史实字段。日期`year/range/traditional/reading-anchor`与显示标签分开；跨年过程和未定年事迹没有补1月1日、12月31日。

## 编辑与验证

`data-source/stories/stories.json`为六部编辑版。`scripts/build_stories.py`离线检查ID、顺序、五卷年份范围与0年、具体定位、论断、来源、既有人物及权力人物，生成`data/stories/{index,navigation}.json`。共和国语义通过只读适配保留原文与来源；不改写其源文件或旧ID。发布构建在权力资料之后、搜索之前重建，指纹和相对引用沿用现有机制。

```sh
python scripts/build_stories.py
python scripts/build_search.py
npm run test:stories
npm run build
npm run validate:release
npm run test:stories-ui
```

`test_stories.py`验证确定性、原共和国适配、精度边界、完整双向索引，并拒绝缺失论断／定位／来源、重复章ID、0年、错卷及失效人物编辑。浏览器测试遍历16部101章，检查全部章节、引用与人物，真实年度／人物往返、原共和国进度、手动已读、刷新返回、防剧透、复制回退、完整导出、键盘、四种宽度与明暗主题，以及根路径和Pages子路径、存储受限、独立HTTP／网络／JSON／深层格式／20秒超时恢复与共享在途请求。

现有全站检索覆盖断言扩展到全部剧本；索引为约1.62MB未压缩文本，上限从1.6调整到1.7MB，仍不包含GIS或全部来源正文。原人物请求断言只允许增加小型剧本导航，继续拒绝完整剧本／地图。新校验、回归与重建一致性纳入原CI。
