# 职官、称号与制度词典

`glossary/` 提供五卷常见术语的独立档案；`#term=caesar`、`#term=dictator` 等稳定ID可分享，`&sense=court` 可定位分期。37条词条覆盖任务书要求的执政官、补任、执政官权军事保民官、十人委员会、独裁官、Augustus、Caesar、Basileus、共帝、摄政、紫室，并补充理解它们所需的授权、议事、军职、宗教与宫廷概念。它是一套有界的阅读词典，不声称穷尽两千年全部职官。

## 阅读

- 目录支持中文、拉丁文、希腊文、别名与忽略重音的检索，可组合分卷、类型、适用年代。年代栏明确采用带符号历史年份，无0年；裸数字在这个专用栏表示公元年。全站搜索原有的裸数字双纪元解释不变。
- 词条列出分期含义、权力与作用、限制与易混淆处、逐项出处、人物和年度例子。分期范围是编辑为阅读和检索选定的适用范围，**不是精确创设／废止年**。如 Augustus 的晚期用法选录到641，不表示此年所有媒介都停用该词。
- Caesar 分别解释家名及皇室语言、晚期副职、十一世纪宫廷位阶。共和国独裁官的任务性任命和晚期非常扩权分列；独裁官不直接等于现代独裁者。共帝、摄政、女性尊号、紫室出身和实际主政分别说明。
- 人物和年度例子是明确编订的阅读关系；有些连接的是生涯或制度背景。例注直说链接年份不必是任职年、受号年、出生年，不能从超链接反推史实。原卷中的回链只显示术语名称和一般阅读说明，不泄露词条例注或未来故事。
- 支持分期焦点、刷新、返回、复制稳定链接及带来源、实际查阅范围和 CC BY-SA 4.0 许可的单条JSON下载；复制受限时可选中手动复制。目录也有完整JSON入口。

五卷页头静态提供“制度词典”。开启正文术语释义后，已渲染的阅读段落和非交互标签中，每段最多两处、同一术语最多一次虚线按钮。按 Tab、Enter 或 Space 打开原生对话框，Escape／关闭按钮关闭并返回触发位置，Tab留在对话框内；完整词条的来源及例子可继续阅读。可以关闭并保存偏好，存储受限时仍可使用。折叠内容在展开后处理。

自动匹配只提供词义导航，不生成历史关系或任职事实。姓名、标题、现有链接、按钮、表单、来源、地图和隐藏防剧透文字均不作词义替换。`Caesar`、`恺撒`、`Augustus`、`奥古斯都`等裸姓名不自动标注，避免把人物误作称号；标题用法由“恺撒称号”“副帝”等明确词语进入。共和国名录中的“军事保民官”专门指向带执政官权的词条，军团职务另立词条。

## 数据与构建

编辑入口是 `data-source/glossary/entries.json`。每个词条有稳定ID、中文／原文／别名、类别、简释、注意项、明确允许内联的短语、相关概念、分期及例子。分期独立保存ID、卷范围、历史年份窗口、含义、权力、限制、引用；例子有分期ID、卷内人物ID、历史年份、说明和引用。共和国例子在这里用负数，构建显式转回原卷正数BC路由。

`python scripts/build_glossary.py` 离线校验并生成：

- `data/glossary/index.json`：完整词条、出处和按原卷人物／年度反查的显式关系。
- `data/glossary/inline.json`：约32KB的正文释义投影，保留分期和注意项、稳定词条链接及例子回链索引。它不包含完整来源目录和例注，不请求五卷资料或完整搜索索引。

构建拒绝重复ID、失效人物／年度／分期／相关词条、无效历史年份、空引用、缺定位／支持论断、来源缺版本／实际查阅范围／限制、无效核对日期、未标中间路径的间接引述、仅凭摘要支持定义，以及同卷多词条抢占同一内联短语。例子必须落在其分期和分卷范围内。日期窗口不会被自动扩展成人物任期。

`build_site.py` 在发布前重建词典，随后重建搜索；原有指纹清理、相对URL和Pages子路径不变。全站搜索为每个适用卷投影一个术语结果，范围与正文按该卷释义选取，跳到同一稳定档案；重复出现是分卷用法，不复制成独立词条。

`shared/glossary-data.js` 为完整和内联两种资料分开缓存、共享在途请求、校验格式、20秒中止及重试。五卷的内联失败只影响术语导航。词典路由和原卷释义均检查当前页面，快速切换不会把旧词条覆写回来；切换原卷路由会关闭旧释义框。源码只用DOM文本节点呈现资料，不把源文或输入当作HTML执行。

## 验证与维护

`test:glossary` 进入 `validate`；`test:glossary-ui` 进入 `test:ui`；PR工作流重建完整／内联词典并检查提交一致性。测试覆盖必需概念、分期差异、双向例子、错误编辑、确定性与体积，浏览器覆盖全部词条和分期、组合筛选、希腊文无重音、空结果、直链与返回、原卷键盘释义、下载、存储受限、防剧透、加载错误和恢复、请求竞态、字面文本、两种部署路径以及320／390／768／1440明暗布局。

修订词义要同步分期、引用与例注。增加人物例子前先确认本库人物确实存在；没有独立人物页时连接已有年度或叙事主体，并在例注说明。不能为凑链接而创建新皇帝，也不按姓名、任期或正文匹配自动生成身份关系。稳定词条ID和分期ID应保留；未来若确需退休，须另设显式兼容迁移。
