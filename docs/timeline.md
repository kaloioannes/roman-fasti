# 五卷任期时间轴

`timeline/` 对读王政、共和国、古典帝国、双帝国与拜占庭的全部**已收录**官职和帝号阶段。它回答先后、共治、争位、复位及帝号与主政的区别，不补建原库未收录的官职、人物或摄政。

## 使用

首页“任期时间轴”、五卷年度页的“对读本年任期”、人物档案的“查看此人的任期时间轴”均可进入。年度入口不请求时间轴资料；人物入口也不依赖跨卷身份索引成功。原有地图、事件、年度和人物URL保持不变。

14个专题入口包括69、238、293—324、1042、908—945、960—1028、查士丁尼二世的失位与复位、东西宫廷、晚期西部宫廷、共和国正任与补任、十人委员会、共和国晚期、传统王期和无0年交界。专题是阅读条件，不是另造一套皇帝名单。

可组合分卷、起止年、姓名／别名、官职／帝号身份、原卷宫廷；姓名支持中拉希文字及忽略重音。宫廷只采用双帝国原有的 `side`，其他卷标“未分宫廷”，不能从地域字符串自动编造东西归属。一次任职、一次帝号阶段分别成条；同一个人的复位不连接失位间隙。

桌面默认显示时间轴，手机默认等价列表，两种视图随时可切换。图形按分卷、宫廷与身份分轨，姓名和条形均可点击，详情列原任期、端点精度、地域、承认、实权说明、人物、起止年度和原出处。每页最多60条，计数为全部匹配阶段；未定年资料单列，不塞进时间坐标。长段可翻页、放大1—16倍、横向滚动或前后移动；列表中的每条也可打开同样的详情和来源。年度选择器接受本段任意非0年，短段还逐年列入口；交界年“五卷对读”会给出两个原卷入口。

筛选、范围、视图、缩放、分页和所选阶段均保存在hash中，可复制、刷新、前进和返回。只有人物参数而没有起止年时，按该人物原档案全部已收录阶段自动确定范围；人物视图允许显示超出分卷年度范围的原始完整任期，例如拜占庭芝诺474—475与476—491两段。分卷年度对读仍按卷界裁切；人物视图明确说明例外，年度链接始终限于本卷实际收录年份。人物链接保留本卷身份，不按同名合并。

例如：

- `timeline/#period=empire&from=69&to=69&view=chart`
- `timeline/#period=empire&from=293&to=324&preset=tetrarchy`
- `timeline/#period=byzantine&from=1042&to=1042&stage=byzantine%3Azoe%3A0`
- `timeline/#period=byzantine&person=byzantine%3Ajustinian-ii`
- `timeline/#period=republic&from=-509&to=-509&view=list`

所有历史年份带符号，公元前为负数；前1年后直接接公元1年。跳回共和国时显式转换回原卷正数BC路由，例如前509年链接仍是 `republic/#year=509`。

## 精度与图形

时间轴使用原有史料数据。可见的起讫窗口**不是补写的即位／退位日期**。

| 数据 | 图示 | 阅读边界 |
|---|---|---|
| 确日 | 很窄的日期窗口，之间为实线 | 日期沿用原卷儒略历；不判断交接日内的时刻 |
| 仅知月份 | 该月为斜纹端点 | 不补1日或最后一天的即位／退位断言 |
| 仅知年份 | 该年为斜纹端点 | 同年短任期可全条斜纹，不能读成全年共治 |
| 约年、日期异说、季节等 | 虚线与斜纹，详情保留原文 | 连续外框包围候选日期，不代表整个窗口都在位；未量化的“前后”不另造正负天数 |
| 传统王期 | 全段专门标示传统性质 | 交接年不证明两位国王共治全年 |
| 未定年 | 独立列表 | 塔提乌斯不自动归到罗慕路斯每一年 |
| 原卷明确空缺 | 单列空缺轨道 | 不由任期缝隙自动推定，也不代表全部政治权力真空 |
| 超出当前视窗或原卷范围 | 条形两端裁切符号 | 原始完整任期仍在详情中，不能把裁切处当即位／退位 |

坐标在每个历史年内按儒略历月长均分日期，内部连续坐标跳过历史0年；不用JavaScript `Date` 或公历转换处理早期年份。日精度端点占一个很窄的“日格”，所以同一天交接也可能视觉相触。所有面积、宽度、分页计数都不用于精确任期天数或“共治总年数”统计。

古典帝国原表的月日保存在 `tenure` 字符串中。本投影只解析明确日期词，支持同一范围末端省略年份的写法；带“约／或／前后”、季节和年初年末的文字保留为不确定标签，不换算成某个季节首日。分号中的拥立、承认和控制首都不是同一事件：使用最早明确的原阶段起点，其他层次保存在完整原文与说明中，例如维特里乌斯1月拥立／4月承认、韦斯帕芗7月拥立／12月控制罗马。不能把“受承认”日期静默替代“起兵”日期。末端没有明确日期时保留原年度，不从持续三周倒推起讫日。

拜占庭、双帝国的 `startDate/endDate` 原样保留 `value/precision/label`，另计算排版窗口；如813年圣诞／814年复活节、约1407／1416年等候选全部保留。每条原有 `start/end` 年度成员范围也保留，不重写原年度表。源资料异说的窗口可能跨年，窗口不表示已确认两年均在任。

## 帝号与实权

`central` 是原卷的主线／宫廷身份，不自动表示独掌实权；`junior` 是共帝头衔，`caesar` 不计作已获奥古斯都帝号。争位、区域、流亡与帝号有争议各自分轨，仍需对读原文的承认与地域说明。

`data-source/timeline/editorial.json` 维护有明确文本依据的实权提示和少数分阶段图带。例如康茂德177年共治／180年起独掌中央，君士坦丁306／312／324年的权力层次，巴西尔二世960年共帝／976年主政，君士坦丁七世913年的名义主帝与受摄政控制、920—945年的共帝阶段。图带使用原文年份，转折年仍只有年精度，不能误读为1月1日交接。

只有源档案明确支持的案例添加这种编订。每个提示记录 `basis`、必须仍能在原人物档案对应字段找到的 `sourceText`、解释及可选 `phases`；源依据变更或越出原帝号任期会阻断构建。阶段与原帝号同起或同止时继承其已知端点精度，不能让年度提示带越过有确日的帝号边界。韦斯帕芗另用原文已有的7月1日拥立及12月控制罗马显示两种层次，12月内确日仍未知。未编订条目明确提示实权尚未结构化判断。此处不是新增全时期“实际权力数据库”，也不凭模型给每个皇帝猜测执政程度。

## 数据与维护

`scripts/build_timeline.py` 离线读取五卷已生成文字档案和专题／实权编辑表，输出 `data/timeline/index.json`。不修改各卷源schema、人物ID、记事、年度成员、任职或既有生成数据。

当前1,582项：王政8项人物阶段＋1项传统空位，共和国1,201项任职＋5项最高官职空缺，古典帝国162段称号，双帝国41段称号＋10项明确宫廷间隔，拜占庭154段称号。合计1,566项任职／称号与16项空缺。它们不是1,582位统治者，也不相加计算跨卷独立人物。来源对象按内容去重，保留标签、URL及原卷类别；投影版本为内容指纹。

阶段定位使用 `period:person:原卷阶段序号`，共和国使用 `republic:person:原年度-原任职序号`。它们定位原始阶段，不随姓名、备注、日期文案修改而改变；若未来重排原任期数组或年度任职数组，应同步维护兼容迁移，不能把旧分享定位悄悄指向另一阶段。当前未进行此类重排。稳定的原卷人物与年度URL始终保留。

重建与验证：

```sh
python scripts/build_timeline.py
npm run test:timeline
npm run build
npm run validate:release
npm run test:timeline-ui
```

发布构建自动重建，资源使用已有指纹机制，支持根路径及 `/roman-fasti/`。页面只加载一份约1.4 MB的文字投影，不请求地图或五卷完整档案；成功值和在途请求共享，20秒超时、HTTP／网络／JSON／结构错误可原页重试，快速换路由不会覆盖当前视图。存储受限仍能使用，复制失败提供可选择的链接文本。

Python和纯JS测试检查全量任职保留、原字段／精度／出处一致、编译不修改输入、幂等生成、日月窗口、无0年、两次复位、两姐妹共治、宫廷空缺与流亡、实权依据、坏数据拒绝。浏览器回归检查全部14入口、五卷往返、组合筛选与分页、缩放分享返回、未定年、异说、失败／超时恢复、请求共享、路由竞争、320／390／768／1440宽度及明暗主题，并以真实发布资源在两个部署路径运行。`validate`、`test:ui` 和PR重建一致性均已接入。

## 本次证据范围

本PR没有新增史实或声称重新直接核读外部文献。实权提示重述现有 `reigns`、地域、备注或人物传记，具体出处可在每条详情打开；所有引用明确为沿用。既有资料自身的日期冲突、王政传统性及研究限制继续保留。238年不能从本库获得完整日级顺序；没有来源的宫廷归属、精确摄政期或新增官职仍为空白，不自动补齐。
