# 早期地图与帝国王朝核查（2026-10-18）

## 地图：错误来自输入几何

Cliopatria v0.2.0 的前500—481年要素只有约12.0—12.4°E、42.1°N的一条网格带；前480—338年也只剩少数矩形单元。两者均排除罗马（12.4964°E、41.9028°N）。原始文件保留，便于复核；把它们平移到罗马或放大，并不能恢复真实疆界。

`data-source/republic/early-territories.geojson`提供五个**独立编辑的区域示意**，以罗马核心及传统前426年菲德奈、前396年维伊、前381年图斯库卢姆和前338年拉丁和约为节点。多边形是本项目绘制的粗略区域，不是从下列研究中数字化提取的边界；文献支持历史节点，不支持每一个顶点。图上使用虚线，标题、说明和来源链接随阶段显示。拉丁同盟整体不涂成罗马领土；前338年示意也保留提布尔、普赖涅斯特在色面之外。飞地、城镇领地的精细边界和阶段内逐年变化未定。

所有五段使用拉丁姆局部视野。前337年起继续使用原Cliopatria阶段，不跨越拉丁战争边界回填较晚的意大利疆域。裁切、简化和D3环方向由离线构建完成。

## 王朝、家族与时代的编辑标准

王朝与家族并非互斥的历史实体：一个家族可以建立王朝，同一王朝也可能通过婚姻、收养而延续。此处`kind`是网页主要标签的编辑选择。优先采用通行的统治继承线名称；没有固定时长或“至少三代”的门槛。同姓、共治、任命和同处一个政治时代，都不足以单独证明王朝成员身份。`era`仍保存时代／政权背景，`dynastyNote`解释交叉亲缘或存疑关系，任期的主帝、共帝、区域与争位身份保持独立。

检查范围为三个帝国卷现有的全部人物归组及55个归组条目（古典24、双帝国6、拜占庭25；跨卷有重复）。未为没有可靠归属的争位者补造谱系。下表记录全部分组的处理；“保留家族”是本项目在多种可能用语中的选择，并不宣称学界绝无“某某王朝”这一用法。

| 卷／归组 | 处理与边界 |
|---|---|
| 古典：尤利乌斯—克劳狄、弗拉维、塞维鲁 | 保留王朝；血缘、姻亲与收养都参与继承，69年及193年的其他竞争者另列。 |
| 古典：涅尔瓦—安敦尼 | 保留通行王朝合称；安敦尼狭义从138年开始，不能把96—192年所有成员理解为单一血缘家族。 |
| 古典：戈尔迪安、瓦勒良、卡鲁斯 | 保留王朝；即使统治短暂也使用通行合称，戈尔迪安一世至三世并非不间断统治。 |
| 古典：君士坦丁、瓦伦提尼安、狄奥多西 | 保留王朝；跨卷狄奥多西名称统一。君士坦丁一世的克劳狄二世祖系宣传不作为已证亲属。 |
| 古典：马克里努斯、腓力、德基乌斯、加卢斯、马克里安、克劳狄二世 | 保留亲属政权的家族标签；同年接替或共治不自动并组。 |
| 古典：泰特里库斯、奥登纳图斯 | 保留区域统治家族；“高卢帝国”“巴尔米拉”整体不是单一共同血缘。 |
| 古典：马克西米安、伽列里乌斯、李锡尼、马格嫩提乌斯、马格努斯·马克西穆斯 | 保留家族；四帝共治是制度，伊利里亚诸帝是集合性称呼，均不另造共同王朝。 |
| 古典：无明确归属 | 保留；包括军事推举、独立争位及缺乏确证谱系的成员。 |
| 双帝国：狄奥多西 | 名称改为“狄奥多西王朝”；马尔基安与普尔喀丽娅的婚姻继承另有说明。 |
| 双帝国／拜占庭：利奥 | 统一“利奥王朝”；芝诺、巴西利斯库斯通过皇室婚姻网络关联；阿纳斯塔修斯一世归入姻亲继承线。尼波斯的婚姻联系保留；安提米乌斯另列独立推举，其岳父是马尔基安，获利奥任命不等于利奥皇室成员。 |
| 双帝国：君士坦丁三世父子、约维努斯兄弟、阿尼基乌斯联系、独立推举 | 保留；君士坦丁三世不因姓名而并入四世纪君士坦丁王朝；阿尼基乌斯联系的推测仍见个人传记。 |
| 拜占庭：查士丁尼 | 补入提比略二世、莫里斯及共帝狄奥多西；收养和婚姻延续518—602年继承线。 |
| 拜占庭：希拉克略、伊苏里亚、阿莫里亚、马其顿、安格洛斯、巴列奥略 | 保留王朝。共帝与姻亲任期分别列明，不以时代标签代替具体谱系。 |
| 拜占庭：尼基弗鲁斯 | 从家族改为王朝，含其子斯陶拉基奥斯、女婿米海尔一世及共帝子；利奥五世另列。 |
| 拜占庭：科穆宁 | 改为王朝；伊萨克一世1057—1059年与1081—1185年主段分开说明。塞浦路斯伊萨克保留区域身份。 |
| 拜占庭：杜卡斯 | 改为王朝，主要指君士坦丁十世一系。罗曼努斯四世保留第欧根尼家族；尼基弗鲁斯三世保留博塔尼亚特斯家族，二者可出现在杜卡斯时代而不是其血缘成员。 |
| 拜占庭：杜卡斯·穆尔祖弗洛斯 | 阿莱克修斯五世另列家族；与十一世纪杜卡斯皇室的确切关系未明。 |
| 拜占庭：拉斯卡里斯／瓦塔齐斯 | 合为拉斯卡里斯王朝。约翰三世是狄奥多尔一世的女婿；狄奥多尔二世、约翰四世是其后裔，母系姓号不构成另一次建朝。旧`vatatzes`筛选链接映射至此组，父系说明保留。 |
| 拜占庭：科穆宁·杜卡斯 | 改为区域王朝，属于伊庇鲁斯—塞萨洛尼基的安格洛斯旁支继承；同姓不与十一世纪杜卡斯合并，也不替代本卷尼西亚主线。 |
| 拜占庭：勒卡佩诺斯、福卡斯、库尔库阿斯、阿尔吉罗斯、帕夫拉戈尼亚、莫诺马霍斯 | 保留独立家族标签，并解释马其顿王朝时期的婚姻、共治或竞争联系。 |
| 拜占庭：第欧根尼、博塔尼亚特斯、坎塔库泽诺斯、斯克莱罗斯、无明确归属 | 保留家族或无归属；坎塔库泽诺斯父子是竞争皇室而非简单抹除巴列奥略继承的独立时代。 |

## 实际对读的研究与公开入口

- Leonora Neville, [*Heroes and Romans in Twelfth-Century Byzantium*, ch.1](https://www.cambridge.org/core/books/heroes-and-romans-in-twelfthcentury-byzantium/twelfthcentury-politics-and-the-house-of-komnenos/6D624C37DC01C6646DBE6BD287D31684)：科穆宁统治与杜卡斯继承、联姻；house、family和dynasty描述不同层次。
- Michael Angold, [“The Empire of the Komnenoi (1118–1204)”](https://www.cambridge.org/core/books/abs/cambridge-history-of-the-byzantine-empire-c5001492/empire-of-the-komnenoi-11181204/69F8F83504B4C0578452EE1F1291437D)：科穆宁、安格洛斯与1204年背景。
- Dimiter Angelov, [*The Byzantine Hellene*（2019，公开卷首、人物表与统治者表）](https://assets.cambridge.org/97811084/80710/frontmatter/9781108480710_frontmatter.pdf)：尼西亚与伊庇鲁斯统治家系的对照。
- [PBE, Michael 7](https://pbe.kcl.ac.uk/data/D54/F73.htm)：尼基弗鲁斯皇室的姻亲关系；资料中的不同纪年与本卷任期分开处理。
- [J. B. Bury, I.XIII §1](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/secondary/BURLAT/13A*.html)：阿纳斯塔修斯的即位与婚姻；双帝国的安提米乌斯见仓库既有Bury I.X来源。
- [Fordham教学年表](https://sourcebooks.web.fordham.edu/byzantium/texts/byzemps.asp)：查士丁尼及尼西亚继承线的公开对照。简表有错漏，用于分组而非覆盖人物专门研究的日期。
- [大都会博物馆统治者表](https://www.metmuseum.org/toah/hd/byru/hd_byru.htm)：尼西亚与恢复帝国顺序的交叉核对。
- [DIR：David Wend论涅尔瓦](https://roman-emperors.sites.luc.edu/nerva.htm)、[Robin Mc Mahon论卡鲁斯](https://roman-emperors.sites.luc.edu/carus.htm)，以及古典卷原有逐组DIR书目：收养继承及短期家族统治的对照。新核查不把所有既有古代来源重新校勘一遍。
