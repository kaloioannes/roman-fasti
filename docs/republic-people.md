# 共和国人物索引与生涯页

PR05 为全部905个既有人物条目建立本卷专页，汇集1,201项已收录任职。入口为 `republic/#people`，人物地址如 `republic/#person=pe9d1a9956a`（恺撒）、`republic/#person=p6faf564142`（奥古斯都）。这不是新增905位经重新考订的人物，也不宣称补齐每个人的全部历史官职。

## 查找与阅读

索引支持中文、拉丁文、原资料标题、既有别名和人物ID，忽略大小写、重音及词首J/I；完整名称或别名命中优先，其余按所选顺序排列。官职、简介状态、实际任职年代、同名档案及多项任职可组合筛选，提供年代／拉丁名／记录数排序和分页。搜索不扫描传记提名来推断身份。年代筛选要求同一项已收录任职满足年份与官职条件，不用最早／最晚任年之间的空隙冒充连续任期。

筛选和页码保存在hash，刷新和前进后退可用。打开人物后“返回人物索引”保留原筛选；直接打开人物时返回全索引。年表人物卡、全站搜索及跨卷总档案均链接完整本卷人物页。旧 `#year=44&focus=person:…` 等年度链接仍定位原卡片；剧本、年度与公元前正数路由保持兼容。

人物页显示全部已收录任职及年度链接、原名和检索名称、译名方式、稳定ID、名录任次、任职备注、年度名录异说、简介与出处，以及同名档案的年代／官职对照。前451年同一人同年不同官职保留为两项，不按年份去重。前43年等补任、选举无效及任内死亡仍以原说明为准。原名录标注任次不等于此页面记录序号，不据其补造缺失任职或日月日期。

133段编写简介原样展示并保留来源；其余只展示任职摘要和已收录记录。193条 `identified=false` 明示身份待考，不生成长传记；已有专条身份也不表示每项传记论断已重新核验。最早和最晚任年只描述库内范围，不是生卒年。年度背景不自动成为本人行动。任职来源使用原任职摘要的名录来源；年度事件引用不冒充具体官职的证据。防剧透沿用全站开关，简介、摘要、任职备注与年度说明都可键盘展开。

## 身份审阅与旧ID

[完整候选清单](republic-identity-review.md)覆盖157组规范化拉丁全名候选和全部193条待考身份，包括没有同名对象的待考条目。每条列稳定ID、专页、已收录年代／官职、当前识别方式和原资料入口。候选可同时包含不同年代同名者和潜在重复；这里只生成审阅线索，没有研究确认的批量合并。本次905个ID、年度成员、1,201项任职及简介正文均不变。

`data-source/republic/person-aliases.json` 独立维护人工旧ID迁移，当前 `redirects` 为空，因为本次没有合并。将来确认迁移时，须先显式修订源身份和年度成员，再为旧ID增加 `{person, note, sources:[{label,url,locator}]}`。目标必须是现存人物；禁止覆盖仍在使用的ID、链式跳转、循环或缺少定位证据的迁移。旧 `#person=…` 在原地址展示目标档案、旧ID及校订依据，不静默重写用户地址。测试中的虚构迁移只用于验证兼容机制，不进入发布数据。

现有链接尚未产生退休ID，所以没有必要凭空添加历史迁移。研究确认合并须同时更新简介身份表、搜索别名、跨卷身份与全部成员引用；不能只填写一个重定向就称完成历史身份整理。未确认时继续保留各档案与其来源。

## 数据与加载

`scripts/build_republic_people.py` 从现有 `records.json`、检索别名和人工跨卷表生成 `data/republic/people.json`；专页名称候选不参与身份合并。投影只保存名称、任职位置、任年、官职、同名候选及旧ID迁移，人物正文仍从原文字档案读取。每项任职以原年度和成员索引指回完整源记录。这是导航投影，不是新增稳定的学术任职ID；改动年度成员后必须重建。

构建同时生成上述Markdown审阅清单，发布构建也自动重建；运行资产按原机制生成内容指纹、采用相对URL，兼容根目录和Pages子路径。原五卷schema保持独立。

人物页不请求地图或剧本。文字和人物投影各自缓存、共享在途请求，20秒超时；HTTP、网络、解析及投影成员错误都可原页重试。索引失败不阻断年度正文。快速改换人物、切回年度或首页时核对路由版本，晚到响应不覆盖新页面。跨卷关联按既有机制独立恢复，不影响本卷资料。禁用本地存储时仍可浏览和切换主题。

```sh
python scripts/build_republic_people.py
python scripts/build_people.py
python scripts/build_search.py
npm run test:republic-people
npm run validate
npm run build
npm run validate:release
npm run test:republic-people-ui
```

数据测试逐项核对全部人物和原始任职的年度、成员位置、角色、任次及备注，检查无源数据改写、同年多职、同名对称性、待考清单完整性、生成物一致性、旧ID迁移的证据与坏映射。浏览器回归使用发布后的指纹资源，遍历905份专页的1,201项任职与同名链接，并测试根目录／Pages子路径、搜索和组合筛选、分页、地址刷新／返回、全站检索、年度与跨卷往返、防剧透、键盘、320／390／768／1440宽度与明暗主题、六类投影失败恢复、过期路由、共享缓存、无地图请求及受限存储。PR工作流纳入重建一致性、数据测试与浏览器套件。

本PR直接对读的是仓库现有名录、专条身份、简介身份与跨卷映射；没有新增人物生卒、亲属、任职或历史身份合并结论，也未将既有来源书目算作本次直接查阅。下一次身份校订应记录实际核读的来源与具体定位。
