# 王政时代：研究、证据与编辑说明

整理日期：2026-10-18。收录范围：前753—前509年，包含两端的245个年度。中文摘要由 FASTI contributors 撰写，CC BY-SA 4.0。现代文章、译本及考古网站只作链接和简短释义，不复制其全文或图片。

## 这份数据库能回答什么

本篇回答的是“按照罗马传下来的王表，这一年属于谁的王期；哪些事迹可以联系到这位国王，哪些确实被放在一个传统纪年节点上”。它不能提供并不存在的前8—6世纪连续年度实录。与共和国执政官年表不同，王期归属不等于当年有任职铭文；与帝国传记不同，王的身世、继承关系与年数往往本身就是叙事传统的一部分。

研究先对读李维卷1、狄奥尼修斯1.72—75的年代讨论，以及普鲁塔克《罗慕路斯传》；随后以狄奥尼修斯2.57—76、4.1—23、4.64—85交叉检查空位期、努马、塞尔维乌斯和末王终结的叙述。现代考古资料用于检查具体的“国王创建”说，而不把考古发现反向塞进一个精确年份。来源与阅览版本详见 [sources.json](sources.json)。

李维在序言已说明起源传说混合人与神；狄奥尼修斯1.72—74公开列出互不相同的建城者与纪元。两位作者的文本都晚于所叙事件数百年；叙述相似不能自动算作两个独立的同时代见证。神化、预兆、人物演说、道德化暴君形象以“传统说”“被描绘为”等语言保留，不改写成已证实的事实。

## 纪年方案：公开一个一致的索引，不伪称唯一真值

采用通行的前753年建城纪元作为索引起点，以狄奥尼修斯1.75及李维1.21、31、35、40、48、60的王期年数顺推：

| 阶段 | 传统持续年数 | 本库交接点区间 |
|---|---:|---|
| 罗慕路斯 | 37 | 前753—前716 |
| 王位空缺 | 1 | 前716—前715 |
| 努马 | 43 | 前715—前672 |
| 图卢斯 | 32 | 前672—前640 |
| 安库斯 | 24 | 前640—前616 |
| 老塔克文 | 38 | 前616—前578 |
| 塞尔维乌斯 | 44 | 前578—前534 |
| 末王塔克文 | 25 | 前534—前509 |

37 + 1 + 43 + 32 + 24 + 38 + 44 + 25 = 244；753 − 509 = 244，而年度桶的数目为245。这些是转移节点间的年数，不是把两个端点均算作完整在位年。譬如前578年同时显示老塔克文与塞尔维乌斯，是表示传统上同年先后掌权；不是两人共治一年。前716、前715两页均显示空位期，是同一个一年区间的两端，不是两年空缺。

这是一种编辑统一法，不是声称狄奥尼修斯本人使用现代通行的瓦罗前753年建城纪元。他在1.74—75将自己接受的纪元与奥林匹亚纪年相连，起点与前753的通行纪元并不相同。本库借用的是王期年数序列，并以统一的现代年份索引对齐既有共和国篇的前509年。

常见另一种排列表把努马终点列为前673、图卢斯终点列为前641；此外也可见老塔克文终点前579、塞尔维乌斯终点前535等。包括端点、王年计数、建城纪元和古今换算的不同可使各表相差一年，不能把不同表的端点混拼后声称得到一套完全一致的绝对纪年。本库固定上表，并在努马、图卢斯交接记事中提醒异说；后续若增加另一套年表，应使用命名的 chronology 对象，整体切换而非逐行替换。

`auc = 754 + year` 只是依本库前753建城纪元计算的 AUC 标签，前753为1，前509为245；它不是发现了这些年份的原始 AUC 文书。网页、JSON与 CSV 均保留传统性质说明。数据库年份为负数，直链为 `#year=-753`；共和国篇仍用旧约定 `#year=509` 表示前509。

## 七王之外：共治与代理

提图斯·塔提乌斯应收录：李维1.13明确给出两位领袖共同执掌王权，1.14记其遇害；普鲁塔克《罗慕路斯传》19、23保存共治与死亡叙事。他不在传统“七王”主序列中，不等于他在传统中不是王。

但不能给他捏造确定的公元前起讫年。普鲁塔克14转述抢婚在建城第四个月，狄奥尼修斯2.30作第四年。两者已不能无条件同步。本库让塔提乌斯 `start/end/traditionalYears` 为 `null`，在罗慕路斯年度页单独提示相关共治传统；不将其自动展开成这些年的“当年在位者”。

罗慕路斯之后的一年空位由元老轮流代理，见李维1.17与狄奥尼修斯2.57—58。代理者的完整名单不能恢复，不虚构一位固定“摄政王”。李维1.22、32亦叙述换王时的 interregnum；未证明持续一整年者，只在交接记事交代，不额外造出完整无王年度。末王在前509失位，而非在这一年死亡；首任执政官只通过共和国交界链接进入，不列为 Rex。

## 逐年事件与未定年事迹的分离

`events.json` 保存46条独立记事：10条落在9个传统纪年节点上，36条为任期内未定年事迹。前509的两条分别讲卢克蕾提娅与驱逐王族／首任执政官，避免把复杂政体转折缩成一个姓名更换。

- `year` 为负整数：仅表示本库传统框架中的节点定位，`dating` 明写传统性质。继位、失位、建城均属于此类。
- `year: null`：事迹只能归到任期或相对叙事，不参与任何当年事件计数。`people` 关联多位人物是叙事关系，不代表这些人在该事发生时均为王。
- 每个年度有 `rulers`、`interregnum`、`events`、`traditions`、`status`、`note`、`sources`。有事件节点者为 `traditional-event`，其余236年为 `no-datable-record`。
- 无可定年事件时，页上明确说“本年无可定年记载”，并提供另栏背景；绝不写成“本年无事”“罗马和平发展”等无证判断。
- “贺拉提三兄弟”“阿尔巴毁城”“建立百人队”“开挖排水渠”等都不因为网上常见一个精确年份而在本库强配年度。未来增加精确年份，须提供具体出处及换算方法，不能从故事顺序每年轮流分配。

| 王期／主题 | 主要核对篇章 | 编辑重点 |
|---|---|---|
| 罗慕路斯建城与制度 | 李维1.6—16；普鲁塔克《罗慕路斯传》14、19、23、27—28 | 神化与遇害异说；萨宾战争与共治年份未定 |
| 空位、努马 | 李维1.17—21；狄奥尼修斯2.57—76 | 非世袭迎立；宗教起源叙事；阴阳合历而非现代太阳历 |
| 图卢斯 | 李维1.22—31 | 阿尔巴、决斗、迁民与惩罚的传统，不虚构战役年 |
| 安库斯 | 李维1.32—35 | 宣战仪式、台伯河交通与移民；奥斯蒂亚考古另论 |
| 老塔克文 | 李维1.34—41 | 移民背景、军政与工程；遇刺后的权力安排 |
| 塞尔维乌斯 | 李维1.39—48；狄奥尼修斯4.1—23 | 身世异说；成熟制度可能被投射到王政 |
| 末王与共和国 | 李维1.49—60、2.1—8；狄奥尼修斯4.64—85 | 暴君叙事、拉丁关系、工程与奉献分开；前509交界 |

## 用考古限制“创建者”叙事

**奥斯蒂亚。** [奥斯蒂亚考古公园](https://www.ostiaantica.beniculturali.it/en/archaeological-sites-and-monuments/ostia-antica/)将安库斯建城列为传说，现有古城最早遗存为前4世纪后半叶的军营。它不能证实“前某年安库斯建成今天看到的奥斯蒂亚”。本库保存李维1.33的建城传统，也说明河口活动、盐场、假定早期聚落和现存殖民军营不是同一命题；考古的晚期遗存也不能直接证明更早河口活动绝不存在。

**城墙。** [罗马城墙虚拟博物馆](https://museovirtualedellemura.romasitounesco.it/en/mura-serviane-english-version/)指出现存主要城墙是前4世纪重建。[卡皮托利欧博物馆](https://museicapitolini.org/en/sede/campidoglio_antico/mura_strade_e_case)另提到前6世纪 cappellaccio 遗迹和前4世纪 Grotta Oscura 阶段。因此本库不用“现存城墙证明塞尔维乌斯某年建成环城墙”，也不简单说所有早期防御工程都不存在。年代与归名应逐项讨论。

**城市宗教。** [圣奥莫博诺发掘项目](https://sites.lsa.umich.edu/omobono/site-description/)对前6世纪神庙阶段提供物质背景。遗址的年代范围可用于讨论王政晚期的城市化，不足以把一次工程落实为塞尔维乌斯在某个公历年的诏令。本库不把考古范围中点造作“当年事件”。

**整体框架。** [Christopher Smith 编《剑桥古代史》图版卷新版节选](https://assets.cambridge.org/97805212/52553/excerpt/9780521252553_excerpt.pdf)提醒，王政年代框架也经过前3世纪以后的学术整理。传统分期与考古演变不能一对一等同。这里的态度既不是七王事迹全部已经证实，也不是考古无法逐年印证就全部删去，而是让不同证据各自保留精度。

**建城与聚落。** [罗马文明博物馆的起源展陈](https://museociviltaromana.it/it/percorso/sala-v-vi-leggende-romane-e-civilt%C3%A0-primitiva-le-origini-di-roma)指出，帕拉蒂努斯山至少前9世纪已有居民。前753年在这里用作传统建城纪元，不等于这个地点到那年才首次有人定居。

**制度的后续变化。** [James Tan (2023), Geography and the Reform of the Comitia Centuriata](https://www.cambridge.org/core/journals/classical-quarterly/article/geography-and-the-reform-of-the-comitia-centvriata/43C5F7259AC095146B22CDF6086F76F3)讨论前3世纪百人队大会的调整及“塞尔维乌斯”旧制的后世记述。本库据此区分制度归名、古代作者描述的制度形态和后来变化；不据该文反推一份精确的前6世纪立法时间表。

## 地点示意与许可

`places.json` 为作者手工设置的粗略经纬度，供相对方位示意。它不是 GIS 边界，不含从现代研究复制的领土轮廓。点位均附叙事关联来源；坐标并非声称由所列古代文本提供。尤其阿尔巴·隆加与科拉提亚仅作区域示意。图上同时出现两王关联的地点，不表示这些地方在交接年都属于罗马领土；不提供面积统计或逐年扩张色块。

地点图复用仓库已有的 World Atlas / Natural Earth 1:50m 海陆底图与 D3 / TopoJSON，使用同一墨卡托投影定位海岸和地点。现代海岸线仅供地理参照，不是王政时代海岸线复原；底图与库的版本及许可见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。所有资源由站点本地提供，无需外部地图服务。

若将来增加考古遗址坐标或历史疆界，应独立提供测绘／GIS来源、许可与日期范围，并保持与王期传统的区别。本次无新增第三方图片、字体或领土多边形。

## 文件、重建与校验

可编辑资料为 `people.json`、`events.json`、`sources.json`、`method.json`、`places.json`；`scripts/build_kingdom.py` 离线生成 `data/kingdom/records.json`。完整数据可在首页下载 JSON，245年年度索引可下载 CSV。CSV只导出年度节点，不把未定年背景混入年度事件；完整出处在 JSON 及页面保留。

`scripts/validate-kingdom.mjs` 检查所有年份、交接双王、空位、塔提乌斯空任期、纪年年数总和、引用及未定年分离。`scripts/test-kingdom.cjs` 用真实 HTTP 检验根路径及 Pages 子目录、边界与搜索、人物直链、地图示意、错误恢复、下载、手机与明暗主题。CI重建后检查生成数据没有漂移。
