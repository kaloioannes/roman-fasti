# 古典罗马皇帝数据库：资料与校订说明

本卷覆盖前27年至395年，采用历史纪年：`-1` 为前1年，其后直接是 `1` 年。共422个年度。原共和国卷的正数 `#year=27` 表示前27年；本卷在 `empire/` 入口中使用带符号年份，避免旧链接改变含义。

## 数据和可复核范围

| 文件 | 内容 |
|---|---|
| `people.tsv` | 稳定ID、中文与拉丁姓名、别名、时代／政权（`era`）、王朝ID（`dynasty`）、归组补充（`dynastyNote`）、来源代号、卷章说明、三段传记；段落以 `~` 分隔 |
| `dynasties.json` | 王朝／家族ID、中文名、类别（`dynasty`／`family`／`none`）、分类说明及来源代号 |
| `reigns.tsv` | 每个头衔阶段一行：人物、起讫年度、身份、地域、可读日期、备注、确定程度 |
| `events.tsv` | 每条记事一行：年度、标题、中文说明、来源代号、定位、年代确定程度 |
| `sources.json` | 来源入口、类别、版本及阅读说明；不是未经阅读的书单数量 |
| `method.json` | 网页直接展示的范围、取舍、日期选择、局限与许可 |
| `imperial-territories.geojson` | 从固定版本Cliopatria选取的帝国相关阶段；原始属性和时间段保留 |
| `../../data/empire/records.json` | 由 `python scripts/build_empire.py` 离线生成的网页数据 |

134位人物包含选录的恺撒及帝号有争议者。**不能把134当作没有争议的皇帝总数。** 所有人都有独立传记；资料很少的争位者说明能确认的行动及证据缺口，不补造出身或施政。年度页面显示的是一年内出现过的阶段，既包含年内先后，也可能包含共治。同一人物的恺撒与奥古斯都阶段可以在晋升年同时出现。

每年有文字，文献的精确度却不均匀。426条记事中，资料无法支持独立分年的项目明确以“跨年背景／过程”等标签呈现，并可在页面隐藏。该标签说明本年的历史处境，不主张某项多年政策恰在这一年颁行。安敦宁·庇护时期尤其如此。约年窗口也不等于可证明连续统治了窗口中的每一天。

## 王朝、家族与时代（2026-10-18）

旧版 `people.tsv` 的 `dynasty` 混合了王朝、时代及区域政权。现在原值完整保留到 `era`，`dynasty` 改为引用 `dynasties.json` 的稳定ID，生成数据升为schemaVersion 2。134位人物均有显式归组；构建时缺失归组或来源会报错。此分类是编辑约定，并不是古代的法定皇帝头衔或完整谱系。

- 10个王朝：尤利乌斯—克劳狄、弗拉维、涅尔瓦—安敦尼、塞维鲁、戈尔迪安、瓦勒良、卡鲁斯、君士坦丁、瓦伦提尼安、狄奥多西。涅尔瓦—安敦尼采用包含收养继承的通行合称，并非单一血缘。
- 13个短期家族组以“家族”标注，涵盖马克里努斯父子、腓力父子、德基乌斯及两子、加卢斯父子、马克里安兄弟、克劳狄二世兄弟、泰特里库斯父子、奥登纳图斯王室、马克西米安父子、伽列里乌斯与外甥、李锡尼父子、马格嫩提乌斯与近亲、马克西穆斯父子；不把每个短期继承尝试都命名为通行“王朝”。
- 其余条目标“无明确王朝归属”，包含未列入上述家族的独立皇帝、争位者及证据不足者；不声称他们没有家属。高卢诸帝没有因为属于同一政权就被合为一族；四帝共治的制度性收养也不据此合为一个世袭王朝。

每人采用一个主要政治家族归组；小李锡尼另注明君士坦丁皇室母系血缘。君士坦提乌斯一世按皇室归入君士坦丁王朝，其四帝共治时期的任期与头衔不变；尼波提安努斯按外甥血缘归入该朝，但仍是争位者。普罗科皮乌斯与尤利安的亲属关系、马尔凯卢斯与普罗科皮乌斯的关系、273年安条库斯与芝诺比娅家族的关系均保留说明，不据模糊谱系扩大归组。王朝标签也不据同年在位推定：69年的加尔巴、奥托和维特里乌斯不属弗拉维王朝，238年的普庇恩努斯和巴尔比努斯不属戈尔迪安王朝。

各组的来源代号在 `dynasties.json` 中列出，网页人物档案直接链接相应研究。主要延用已有DIR署名专题（如 [Valerian and Gallienus](https://roman-emperors.sites.luc.edu/gallval.htm)、[Constantius I](https://roman-emperors.sites.luc.edu/chlorus.htm)、[Nepotianus](https://roman-emperors.sites.luc.edu/nepot.htm)、[Procopius](https://roman-emperors.sites.luc.edu/procopis.htm)）及巴尔米拉专题，并结合各人原有古代证据定位。君士坦丁王朝从君士坦提乌斯一世起的通行分期亦可对照 [Livius概述](https://www.livius.org/articles/dynasty/constantinian-dynasty/)；这些分组不是从网页索引按年份自动推断的。

年度卡片、人物索引和完整档案均显示归属。年度及档案标签可跳至人物索引筛选；新链接使用稳定ID，例如 `#people&dynasty=severan`。旧版以中文王朝名分享的筛选链接仍可解析；旧时代筛选值按原条件保留，并在选择框中注明“时代／政权”，仍可与姓名和身份条件组合。姓名、王朝中文名与原时代／政权背景均可检索。

## 研究路径

1. 先建立中央与共帝的任期骨架，再按高卢、巴尔米拉、海峡政权与争位事件补充，最后单列副帝及证据争议。
2. 古代叙事按其覆盖范围使用：狄奥与塔西佗用于早期帝国，希罗狄安用于180—238年，三世纪后段交叉使用简史、钱币及专题研究，阿米阿努斯用于353—378年，晚期另对读法律与教会史。
3. 以DIR署名专题论文的注释和讨论校对姓名、政治关系与争位者。**不机械采用其皇帝总索引**：总索引中存在卢基乌斯·维鲁斯卒年、狄奥多西即位年等简表错误，个别论文之间也有年代分歧。
4. 钱币用以确认帝号及发行关系；铭文、纸草和法律用于补充。钱币上的胜利、和平或复兴措辞属于政治表达，不能直接当作社会状况的统计。
5. 中文条目是综合重述。卷章定位是核查入口，不代表古代作者已有现代分类术语；未声称通读未获取全文的付费专著。资料校订日期为2026-10-17。

## 主要证据入口

- [卡西乌斯·狄奥《罗马史》](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Cassius_Dio/home.html)：使用卷53—80；后期多经节略本保存，版本卷号可有差异。
- [塔西佗《编年史》](https://classics.mit.edu/Tacitus/annals.html)、[《历史》](https://classics.mit.edu/Tacitus/histories.html)、苏埃托尼乌斯《十二恺撒传》、奥古斯都《功业录》：彼此对照元首制、继承和战争叙事。
- [希罗狄安](https://www.livius.org/sources/content/herodian-s-roman-history/)及[阿米阿努斯](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Ammian/home.html)：区分目击、转述、道德评价及作者偏好。
- [De Imperatoribus Romanis（DIR）](https://roman-emperors.sites.luc.edu/)：采用大学镜像中的署名人物研究和争位专题；每个条目保留相应研究链接。
- [Estiot1996：西尔班纳库斯](https://www.persee.fr/doc/numi_0484-8942_1996_num_6_151_2087)与[大英博物馆标本](https://www.britishmuseum.org/collection/object/C_1937-1203-1)：解释253年与旧说菲利普时期的日期差异。
- [Estiot／Salaün2004：多米提安二世](https://www.persee.fr/doc/numi_0484-8942_2004_num_6_160_2558)；[Abdy2009](https://doi.org/10.1017/S0003598X00098963)：新出土同模钱币支持人物及帝号真实性；准确任期次序仍不确定。
- [PLRE I 的Domitianus6数据入口](https://connectinglateantiquities.org/text.html?id=plre-1-domitianus-6)：核对埃及297年事件的日期窗口；配合DIR的Domitianus/Achilleus专题，不把索引当完整传记。
- [OCRE](https://numismatics.org/ocre/)：美国钱币学会与ISAW的罗马帝国钱币目录，辅助说明头衔与发行。

## 重要取舍

| 问题 | 本卷处理 |
|---|---|
| 奥古斯都起点 | 前27年受号；此前事迹见传记和共和国篇 |
| 共帝还是继承人 | 卢基乌斯·维鲁斯161年、康茂德177年、盖塔209年等取得奥古斯都；保民官权或恺撒称号单列 |
| 四帝共治 | 两位奥古斯都与两位恺撒同时呈现；副帝不混算为已升奥古斯都 |
| 君士坦丁306年 | 军队称其奥古斯都，与伽列里乌斯只承认其恺撒资格并列说明 |
| 马克西米安复出 | 286—305、306—308、310三段，不把309年误作连续在位 |
| 巴尔米拉 | 地方王权从更早开始；本卷帝号阶段采用272年，并保留271年等异说；不把奥登纳图斯自动列为罗马皇帝 |
| 稀见钱币皇帝 | 西尔班纳库斯约253年；多米提安二世约271年，均明示不确定性 |
| 文学所见争位 | 普里斯库斯、利基尼亚努斯、塞普提米乌斯、福斯提努斯有独立条目，资料局限与日期窗口明列 |
| 帝号存在争议 | 奥勒奥卢斯、阿基琉斯、四世纪菲尔穆斯、273年安条库斯放在单独辅栏 |
| 不可靠僭主清单 | 不将《三十僭主》全表机械收入；乌尔巴努斯、273年埃及菲尔穆斯等不列作确定皇帝；斯蓬西安努斯仍有真伪与解释争议 |
| 395年 | 狄奥多西死后两位已经在位的儿子分治；保留两人完整任期，但逐年页止于395年 |

## 地图

与共和国篇采用相同的 [Cliopatria v0.2.0](https://github.com/Seshat-Global-History-Databank/cliopatria/releases/tag/v0.2.0)，固定版本便于复核。数据集来自[Seshat](https://doi.org/10.1038/s41597-025-04516-9)，其边界按若干历史框架年份采样，不是逐年精确测绘。图注说明采用的阶段；内战、共治和区域政权的政治关系须结合年度文字阅读。政治据点只定位，不声称始终是唯一首都。

选取源数据后，`python scripts/build_imperial_map.py` 生成网页轮廓。它沿仓库现有的Natural Earth海岸线裁切、轻度简化并转换为D3所需的环方向；需要Shapely。普通文本重建与网站构建不依赖Shapely或网络。

具体处理可从脚本与GeoJSON属性复核：源子集保留60个原始要素，网页合并成57个外缘阶段。源数据把高卢标签延到282年、把巴尔米拉标签用于261年起的地方权力，均不直接复用为本卷帝号年表。116年扩张高峰借用源117—126年轮廓；117—126年改用相邻127—153年收缩轮廓近似，避免把哈德良撤军后的两河地区仍画作持续占领。图注逐项说明这些近似。源阶段止于0的记录在网页止于前1年。395年的东西轮廓合并显示外缘，不把内部行政分治描绘成两个现代主权国家。

来源固定到提交 `ad28a691b7c07c1fca89d0e0636d324667d2a258`、上游zip的Git blob `cefab0f4b622e2e7fb3daf68d4f461f83991204c`；筛选条件、来源及许可证保留在源GeoJSON顶层。不依赖实时网络接口或在线地图瓦片。

## 验证

`npm run validate` 同时检查两卷。帝国篇检查422年连续性、来源代号、三段传记、每个任期与年度的完整对应、地图覆盖及环方向，并针对69、238、260、293、306、309、395等年设置历史边界回归。另校验全部王朝ID、分类来源、边界人物与家族归属，防止把时代、共治或区域政权误作王朝。

`python scripts/build_site.py` 为两卷生成带内容指纹的资源。`npm run test:release` 在真实HTTP与GitHub Pages子路径下检查旧版缓存升级及帝国篇交互；`npm run test:imperial` 单独运行帝国篇。浏览器测试覆盖任期转换年份、全部人物传记、前后纪元、全部王朝／家族筛选、标签跳转、组合过滤与刷新恢复、旧筛选链接、无效地址、网络失败重试和四种宽度的明暗主题。
